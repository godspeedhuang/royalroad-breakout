## What Project 1 asks for

Use predictive AI to address a business or policy problem, in one of two ways:

- machine learning on tabular data **plus** deep learning on unstructured data, combined in one project; or
- a more ambitious deep learning project on unstructured, possibly multimodal, data.

Core work:

1. Turn the problem into a well-defined prediction task with clear inputs and outcome.
2. Prepare the data.
3. Rigorous model selection and validation.
4. Compare against meaningful benchmarks: a predictive baseline, a business rule, other modeling approaches.
5. Quantify the practical impact of better predictions (revenue, cost, efficiency, service, risk); visualizations are encouraged.

## Four questions every project answers

1. **What problem are we solving?** The target stakeholder, the current process or decision, and the opportunity to improve it.
2. **What can AI do?** Obtain suitable data and design an AI solution.
3. **Does it work?** Evaluate rigorously against suitable benchmarks.
4. **Does it matter?** Translate technical performance into managerial or societal impact.

## Deliverables

| Deliverable | Audience | Content |
|---|---|---|
| 2-minute video | Target stakeholder | A self-contained demo or pitch |
| Deck, 5–10 slides | Target stakeholder | Problem, AI solution (data, modeling approach, key findings), business impact, recommendations |
| GitHub repo + one-page README | The organization's data scientists / ML engineers | Runnable code and instructions to reproduce the results |

The video and deck answer "why it matters"; the repo answers "how it was done".

## What the grading values (stated in the handout)

- The goal is not a high-accuracy model or a complex workflow but **using AI to solve a problem and showing practical value**.
- Scope should be ambitious but focused: meaningful analysis and evaluation that fits in a few weeks.
- **A simple but valuable model beats a technically complex system whose value is unclear.**
- A good project = a meaningful problem + a well-designed solution + rigorous evaluation + a convincing impact + clear communication.
- Projects that will be public in a portfolio must not contain confidential, proprietary, personally identifiable or otherwise restricted data.
