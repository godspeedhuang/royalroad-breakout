Royal Road Breakout

MIT 15.071 Project 1. Each point is one of 45,245 web serials first released 2016–2024, placed by a text-embedding-3-small embedding of its first three chapters. Colour by top10 to see which books ended up in the top 10% of followers within their release quarter.

PCA view
Linear projection (first two components explain 10.4% of variance). Includes the per-quarter centroid of top-10% books, so you can follow how the hits move over time. UMAP view
Non-linear projection. Better for seeing clusters of similar stories; distances between clusters are not meaningful.

First load downloads about 110 MB (DuckDB-WASM + data). Excerpts are capped at 300 characters and link back to royalroad.com; author names are removed.
